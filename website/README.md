# TokenFlow Website

This folder is reserved for the public-facing TokenFlow website.

## Purpose

- Product landing page and feature showcase.
- Download links and install instructions.
- Canonical usage guide, FAQ, and screenshots.
- Release highlights and privacy summary.

## Site map (planned)

- `/` — landing page
- `/docs` — usage guide
- `/download` — installers and platform notes
- `/changelog` — release highlights
- `/privacy` — privacy statement

## Content ownership

- Usage documentation lives here.
- Architecture and release runbooks stay in the repository root and `packaging/` / `flatpak/`.
- Do not duplicate the configuration reference or packaging matrix; link to the repository docs.
